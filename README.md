# Os Ressurgentes — piloto misto

Cópia da landing page existente, adaptada para homens e mulheres em uma nova fase. A versão publicada no Lovable permanece separada desta proposta de atualização.

## Oferta

10 rodadas de 4 participantes, R$250 por pessoa: entrevista individual (60 min), Jogo do Herói coletivo misto (240 min), plano coletivo (60 min) e apoio de IA por 30 dias. Preço-alvo futuro: R$697.

## Executar

```sh
npm install
npm run dev
npm run build
```

## Revisão e integração

- `src/lib/launch-config.ts`: oferta e conexões. O checkout começa desabilitado; só habilitar após validar as condições reais.
- `docs/lancamento-piloto.md`: decisões pendentes, testes e futura integração com Lovable.
- `docs/videos-30s.md`: roteiros das três versões — mulheres, homens e misto.
- `docs/brief-original.md`: referência anterior preservada; não é a especificação da nova oferta.

Sem publicação, automação de Instagram, formulário de leads ou pagamento configurados por esta alteração. A página permite conhecer a oferta e entrar em contato pelo WhatsApp. Nenhuma conversa reserva vaga automaticamente.
