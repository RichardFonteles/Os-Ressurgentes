# Hospedagem Netlify

O projeto usa o adaptador oficial `@netlify/vite-plugin-tanstack-start`, sem depender da hospedagem Lovable.

## Conectar uma vez

1. Acesse https://app.netlify.com/ e entre com GitHub.
2. Escolha Add new project → Import an existing project → GitHub.
3. Autorize apenas o repositório RichardFonteles/Os-Ressurgentes.
4. Selecione a branch main. Deixe a pasta base vazia.
5. O netlify.toml configura npm run build, dist/client e Node 22.
6. Revise o primeiro deploy antes de divulgar. Não habilite cobrança automática.

Não é necessário fornecer senhas ou tokens neste chat.
